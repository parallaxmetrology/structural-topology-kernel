# Changelog

## 0.1.0 (2026-10-21)

First public release of the research kernel (June 2026) as `stkernel`: frozen 50-coordinate kernel, micrograph preparation, `measure`/`measure_many`, `STKFeaturizer` (matminer-compatible), `stk` CLI, benchmarks and feature tables that reproduce the recorded UHCSDB, bainite and permeability results exactly.
