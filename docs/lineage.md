# Lineage

- **Name.** The Structural Topology Kernel was developed in June 2026 within the Parallax Metrology program. Its research file was `vtl_materials_kernel.py` ("VTL" being the program's earlier umbrella name), and recorded results use the label `VTL-50` for what is STK-50 here. `stkernel/_stk50.py` is that file, with only its docstring and one comment reworded; `tests/test_golden.py` checks it against the original.
- **Before STK.** An earlier materials study used a 2-coordinate port of the image kernel (`bdf_cv`, `glcm_cv`) and concluded the instrument collapsed into two-point statistics. That conclusion came from the port, not the instrument; the full kernel replaced it.
- **Corrections, kept in the record.** The first UHCSDB result (0.926) split by image and leaked specimens; an external review caught it, and the grouped 0.832 replaced it. A claimed "+0.164 beyond S2" was retired as near-tautological (one channel vs fifty) and replaced by the union test. The permeability result was first read as "adds nothing" and corrected by bootstrap to "adds a small nonlinear amount". In October 2026 a re-evaluation against a stronger baseline (an 83-feature texture set) retired "beats conventional descriptors": STK still beats HOG, and Haralick where it was run, but the texture set ranks UHCSDB classes better ([known-issues.md](known-issues.md) §13).
- **Paper.** [STK: an interpretable multi-task descriptor for materials](https://www.parallaxmetrology.com/STK_Materials_Paper.html) (2026). Overview: [parallaxmetrology.com](https://www.parallaxmetrology.com/stk_pm.html).
- **Code recovered for this release.** Several analyses (the grouped benchmark, ablation, union and ambiguity checks, the permeability bootstrap) were run as one-off scripts and their results saved without the script. For this repository they were recovered from the original session record and rewritten as `benchmarks/*.py`; each reproduces its recorded result exactly on the reference platform. The pore-connectivity features for the bootstrap were recomputed with the recovered code and are shipped in `data/permeability/`.
